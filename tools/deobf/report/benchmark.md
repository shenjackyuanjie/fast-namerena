# 性能记录（md5.js 0.5.5）

运行时：Bun 1.4.0，Windows x64，独立进程取中位数（前两轮 5 次；第三轮最终验收 7 次）。

## 第三轮验收（0.5.4 → 0.5.5，同机背靠背）

先跑 0.5.4（`md5.stage0.js`），紧接着跑 0.5.5（`md5.js`），两边各 7 次独立进程：

| 项目 | 0.5.4 | 0.5.5 | 变化 |
| --- | --- | --- | --- |
| wall（进程启动到退出） | 3498.7 ms | 3467.3 ms | -0.9% |
| load（require 到可用） | 18.6 ms | 17.4 ms | -6.5% |
| fight ×200（3 人） | 161.1 ms | 149.9 ms | -7.0% |
| win_rate(1000) | 233.2 ms | 231.4 ms | -0.8% |
| score(10000) | 3026.4 ms | 3002.7 ms | -0.8% |
| 子进程内合计 | 3438.0 ms | 3406.7 ms | -0.9% |

该轮另外跑了三组 5/7 次采样（`benchmark-round3*.json`），方向不一致（+0.9% / +4.9% / -4.4%），说明本机噪声约 ±5%；没有任何一组显示 0.5.5 有系统性退化。战斗分支高度特化，网页端不可直接对照，性能只与同分支的 0.5.4 自身比较。

原始数据：`benchmark-round3-old-final.json`、`benchmark-round3-final.json`。

## 第一轮验收（清理前 → 0.5.3，同机背靠背）

先跑清理前基线，紧接着跑清理后的 `md5.js`，两边条件一致：

| 项目 | 清理前 | 清理后 | 变化 |
| --- | --- | --- | --- |
| wall（进程启动到退出） | 3266.8 ms | 3266.0 ms | -0.0% |
| load（require 到可用） | 21.3 ms | 20.2 ms | -5.2% |
| fight ×200（3 人） | 152.5 ms | 153.2 ms | +0.5% |
| win_rate(1000) | 223.6 ms | 226.7 ms | +1.4% |
| score(10000) | 2804.9 ms | 2785.2 ms | -0.7% |
| 子进程内合计 | 3206.9 ms | 3207.8 ms | +0.0% |

全部落在 ±3% 噪声范围内，验收通过。更早一次背靠背对比（基线 3620.9 / 3424.1 ms wall）观察到约 3.5%~5.4% 的提升，说明清理方向有效，但机器状态波动大于本次差异。

原始数据：`benchmark-baseline-recheck.json`、`benchmark-final.json`。
